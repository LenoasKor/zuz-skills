## Decal Pack 작업 기록 판단

등록 불필요 → 기존 기록 재사용 → 새 기록 필요 순서로 판단합니다. 읽기 전용 조사·기존 변경의 커밋/push·재검증·동작 계약을 바꾸지 않는 작은 변경만으로 티켓을 만들지 않습니다. 독립 목표·새 기능·계약 변경·독립 결함·실제 장애는 해당 기록으로 추적하며 사용자의 명시 등록 요청을 존중합니다.

등록·재개·종결·출시 단계 판단이 필요할 때 `contracts/its-tracking-policy.md`와 해당 ITS 스킬을 읽습니다. 이미 같은 정책을 읽었다면 내용 변경이나 문맥 소실 시에만 다시 읽습니다. 등록 면제는 권한 면제가 아닙니다. 다른 저장소 접근·push·merge·배포·정산·삭제·비밀값·비용의 승인, source revision과 정확한 대상 확인, 대상 밖 변경 보존을 유지합니다.

Decal 소유 세션은 광고된 Native 도구만 사용하고 거절·부재 시 우회하지 않습니다. 외부 Host는 설치된 `contracts/task-work-bug/its-register.mjs`의 광고·검증된 기능을 사용합니다. 파일·도구·승인·검증 결과가 없으면 만들어내지 않습니다.
