# 세션종료 준비

Decal 소유 세션의 상태 변경 확인은 `decal_ui.request_confirmation`으로 요청합니다. 외부 Codex/CLI host는 같은 대상·영향을 일반 텍스트로 승인받습니다.

## 인계 형식

- **인계할 작업**: 기준 문서와 목표
- **현재 상태**: root·branch·HEAD·dirty, 실제 완료·진행·차단, 코드와 실행 빌드의 일치 여부
- **결정된 내용**: 확정된 결정·이유·승인 출처와 유효 범위. 인계 자체는 승인 아님
- **다음에 할 일**: 다음 실행 한 가지, 담당자, 차단 해제 조건. 이미 실패한 접근은 이유를 함께 남겨 반복 방지
- **주의사항**: 변경 파일, 검증 명령·결과·revision/Build ID, skip·미검증, 보존할 다른 작업. 원시 대화·비밀값·내부 추론은 복사하지 않음
