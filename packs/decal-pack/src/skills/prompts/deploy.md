# 배포

Decal 소유 세션의 배포 확인은 `decal_ui.request_confirmation`으로 요청합니다. 외부 Codex/CLI host는 같은 대상·외부 영향을 일반 텍스트로 승인받은 뒤 동일한 재검증 규칙으로 실행합니다.

사용자에게는 내부 명령 대신 배포 대상과 외부 영향을 쉬운 말로 설명합니다.

프로젝트의 출시 단계는 Showcase 빌드 등록·테스트 흐름이 자체 경계에서 확인하며, 일반 배포 스킬의 입력이나 중단 조건으로 사용하지 않습니다. 실제 배포는 기존 정산 영수증·소스 결속·사용자 승인 경로를 그대로 통과해야 합니다.

출시 단계 판정이 필요한 연계 흐름에서 저장값이 누락·null·`unset`이면 `pre_live`로 해석하고 사용자에게 단계 선택을 반복 요청하지 않습니다. 명시 저장된 `live`는 유지하며, 폴백은 저장값을 수정하거나 배포·정산·비용·비밀값·외부 서비스 변경 권한을 추가하지 않습니다.
