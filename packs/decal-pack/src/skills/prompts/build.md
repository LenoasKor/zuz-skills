# 빌드

Decal 소유 세션의 상태 변경 확인은 `decal_ui.request_confirmation`으로 요청합니다. 외부 Codex/CLI host는 같은 대상·영향을 일반 텍스트로 승인받습니다.

사용자에게는 내부 명령 대신 확인할 빌드 대상과 변경 영향을 쉬운 말로 설명합니다.
