# 빌드

Decal 소유 세션의 상태 변경 확인은 `decal_ui.request_confirmation`으로 요청합니다. 외부 Codex/CLI host는 같은 대상·영향을 일반 텍스트로 승인받습니다.

사용자에게는 내부 명령 대신 확인할 빌드 대상과 변경 영향을 쉬운 말로 설명합니다.

프로젝트의 출시 단계는 Showcase 빌드 등록·테스트 흐름이 자체 경계에서 확인하며, 일반 빌드 스킬의 입력이나 중단 조건으로 사용하지 않습니다.

## Showcase 전용 출시단계 변경

- 외부 host인지가 아니라 현재 제공된 공식 변경 capability를 기준으로 `지원됨`, `지원되지 않음`, `확인 불가`를 구분합니다.
- 지원되는 경우 사용자 선택과 현재 `expectedStage`를 결속하고, 성공 영수증을 받은 뒤에만 변경됐다고 판단합니다. `stale`은 거부가 아니라 최신 정본을 다시 확인해야 하는 경쟁 상태입니다.
- 직접 호출 가능한 capability가 없으면 일반 빌드는 계속합니다. Showcase 전용 요청만 연결된 Decal Desktop 또는 Decal Remote의 설정 화면에서 선택하도록 안내하고 최신값을 다시 읽습니다.
- 읽기 전용 reader는 설정 도구가 아닙니다. Decal 앱 데이터 파일을 직접 편집하거나 Git·Task·배포 이력으로 단계를 추정하지 않습니다.
